# Sterio Server

This is the standalone server project. Keep all server implementation, Docker/deployment configuration, installation documentation, exported images and server build artifacts here. Use `dist/` for deliverable archives and `work/` for temporary build files and logs.

The React Native client lives in `../sterio`; client-side provider integration belongs there.

The user requests manual testing: do not run automated tests or playback tests unless explicitly requested.

## Documentation

Read `docs/HANDBOOK.md` first: it describes how this project works, how it is built and released, and the working rules. Keep it current: any change to behaviour, architecture, APIs, data, settings, build or release steps updates `docs/HANDBOOK.md` (and the topic file in `docs/` it concerns) in the same change.

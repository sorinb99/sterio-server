PAIRED DEVICES

Devices & nicknames

Users can set a nickname in Sterio Settings, for example Sorin iPhone or Sorin Mac. Nicknames identify devices in live playback and reports; Apple ID is not collected. You can also edit a label here.

NETWORK STREAMERS

Streamers

BluOS players (Bluesound, NAD, …) and UPnP/DLNA renderers on your network. The app chooses a streamer as its output; the streamer then plays straight from this server, and the server keeps the queue going while the app sleeps. DSD is sent as FLAC to streamers without DSD support.

YOUR COLLECTION

Library scan

CUE ALBUMS

Split albums into tracks

Write each CUE chapter as its own FLAC in a hidden .sterio-tracks folder inside the album (not listed by file browsers), for fast start and exact seeking. The original file and CUE stay unchanged; the app's Full file setting still plays them.

CONNECTIONS

Linked servers

Enter the other server's address and press Connect: it shows a connection request, and its owner accepts it on its page or in the Sterio app. Show another Sterio server's library here. Apps connected to this server browse both libraries; tracks from the other server stream through this one, so apps never connect to it. Songs this library already has are hidden, and extra tracks of an album you already have join that album.

Share this library with another server

Generate a one-time server key, valid for 10 minutes, and enter it with this server's address under Linked servers on the other server. It shares this library's own tracks, never tracks from servers linked here.
